# PROJECT CHIMERA — Horizon x GTA Fusion Monster

A 48-Layer Recursive Hybrid Engine with Singularity Convergence. An interactive web app exploring the complete system architecture specification for fusing Horizon and GTA into a single unified game universe.

## Features

- **Interactive 48-Layer Explorer** — Browse every layer from Foundation to Void Ascension with full technical specifications
- **4 Architecture Tiers** — Foundation, Advanced Engine, Singularity, and Void Ascension
- **Data Flow Diagram** — Visual pipeline from player input to rendered frame
- **Scenario Playthroughs** — Cross-world car chases, time loop missions, and god-mode finales
- **Technical Specs Dashboard** — Performance, stability, scalability targets, error codes, and glossary

## Tech Stack

- Vite + React + TypeScript
- Tailwind CSS
- Lucide React icons

## Build

```bash
npm install
npm run build
```
